      Naming

      Container names are built from these templates. A console can use {account}, {accountId}, {role} and {org}; a portal and an Okta admin console can use {org}, the organization's label.

      Colours

      The first rule whose text appears in a container's name sets its colour. Separate alternatives with commas; letter case is ignored. A name that matches no rule gets a colour of its own, which never changes.

        No rules. Every container gets a colour of its own.

        Managed containers

        The containers this extension created. It never renames or removes any other container.

        None yet. One is created the first time a portal, a console or an Okta admin console is opened.

          Remove these containers?

          None of them has a tab open. Removing a container signs you out of everything in it. It is created again the next time it is needed.

            Backup

            An export holds the names, colours, switches and the list of organizations with their labels. It does not hold containers, account names or site access, so after an import each organization has to be granted access again.
